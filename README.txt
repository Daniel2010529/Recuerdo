RECUERDO · INNER LIGHT

1. Abre la carpeta en Visual Studio.
2. Mete tus fotos en wwwroot/photos/ con estos nombres:
   foto1.jpg, foto2.jpg, foto3.jpg, foto4.jpg, foto5.jpg, foto6.jpg
3. Crea wwwroot/music/ y coloca tu archivo de audio como:
   inner-light.mp3
4. Ejecuta con Ctrl+F5 o desde la terminal:
   dotnet run
5. Abre la dirección que indique Visual Studio.

IMPORTANTE:
El proyecto NO incluye la canción Inner Light. Debes añadir un archivo de audio que tengas derecho a utilizar.
Puedes cambiar textos y tiempos directamente en wwwroot/index.html.

CARACTERÍSTICAS:
- Pase de fotos automático con transición cinematográfica.
- Zoom suave tipo Ken Burns.
- Contador y puntos de navegación.
- Botones anterior / pausa / siguiente.
- Música de fondo.
- Pantalla inicial para que el navegador permita iniciar el audio.
- Diseño responsive para móvil y PC.
